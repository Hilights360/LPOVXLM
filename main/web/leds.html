Connecting...

When enabled, brightness rises evenly from the center setting at the hub to regular brightness at the tips. The center is limited to regular brightness; 0% regular brightness turns everything off.

All light tests use saved brightness and need no SD card. Rotation stability tests require rotation and magnetic pulses; the Hall sensor test lights while the sensor is active.

LED tests

Start with solid red to check the entire strip. Solid colors refresh continuously.

Color fade keeps every pixel the same color on a 12-second cycle. Arm RGB test chases individual pixels. Connector colors assigns red, green, blue, and white to arms 1-4.

White blinking switches all arms on for 500 ms and off for 500 ms, using saved brightness and center fade. It works while stationary and can remain active during an SD read load test.

Rotation stability tests

Paint fixed colors around the disk using the saved spoke count and one magnetic pulse per revolution. Each spoke lights the full length of the arm.

Alternating spokes repeats red, green, blue, white, one color per spoke. The pattern stays fixed to the magnetic reference so drift or uneven widths are visible.

Uses current RPM, image spokes and recent LED transfer timing with a timing margin. Saves automatically and keeps adjusting with this page closed. Takes precedence over angular strobe; uncheck to restore manual duty and strobe. The level pattern keeps its fixed widths.

Both tests use playback timing, phase offsets, and 20 MHz DMA. They replace current playback and stay dark without magnetic pulses. Adjust the spoke count, angular strobe, and phase in Controller settings. Stop lights ends either test.

Short flash verification

Compare the current sequence using short flashes on the existing four 144-pixel APA102 arms. Run near 100 RPM. Each flash ends with black in the same hardware transfer.

Wider flashes fill more of each spoke but can soften edges. Changes apply immediately while the test is running. A flash is skipped if it cannot finish within its spoke.

Play a sequence first. This temporary test uses your brightness setting and overrides duty and angular strobe. Adjust brightness above while comparing spoke width and smearing. Normal timing returns automatically after 30 seconds. Starting the test keeps saved settings unchanged. Short flashes reduce average brightness. Reported pulse width is calculated from the transmitted data, not an optical measurement.

Arm offset and level

Shift all arms together relative to the magnetic sensor. Start the level pattern while the unit is rotating, then turn the pattern until the green half is on top with a level edge and the middle red spoke points straight down.

Adjustments apply and save immediately, including during playback. The offset is retained after restart. Positive degrees move the image against the rotor's direction. Rotation buttons follow the viewing side selected in Wiring setup.

This pattern replaces playback and needs magnetic pulses, but no SD card. It uses saved brightness, center fade, arm wiring and individual arm trims. The green half and three red spokes have fixed widths; display duty, angular strobe and image spoke count do not affect this pattern. Stop level pattern turns the lights off.

This is the same global offset shown in Controller rotation timing. Individual arm trims remain available there if one arm needs a separate correction.

Wiring and signal check

SignalConnectorGPIOESP level

GPIO numbers refer to the ESP header. Fewer active arms use the beginning of this list. Pin assignments are fixed to the PCB map. During normal data transmission the displayed levels are idle snapshots, not waveform measurements.

This check stops LED data and drives only the selected signal. It is for voltage measurements, not a lighting pattern. Stop lights restores normal output and blanks the strips.

  1. Use a common ground reference. Select the clock, hold LOW, then HIGH. Expect about 0 V then 3.3 V at the ESP header.
  2. Follow that change through the clock buffer to CI at the strip input. A 5 V buffer should produce a HIGH near its supply voltage.
  3. Repeat for each arm's DI. If an input changes but its buffer output does not, check the buffer's power, enable, and direction connections.
  4. Confirm the strip is connected at DI/CI, not DO/CO. Then stop the signal check and try solid red.

For SN74AHCT245 specifically, /OE must be LOW; DIR must match the chosen input/output sides. Verify the fitted chip before using its pinout.

DMA speed test

To find the highest clock rate your strips display correctly, open the Strip speed test page for sustained patterns and visual results.

Keep the spinner stationary. Start at 4 MHz, then try 8 and 16 MHz if the colors look correct. The test flashes red, green, blue, and white arms with a moving white marker, at up to 10% brightness.

Measures 10 GPIO transfers and 100 DMA transfers, including alternating black frames, in about six seconds. No Hall pulse or SD file is needed. Normal GPIO output resumes afterward. A zero brightness setting keeps the test dark.
